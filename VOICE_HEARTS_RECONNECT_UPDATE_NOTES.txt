ALPHA MATE - VOICE / HEART / RECONNECT UPDATE

Changes made in this source update:
1. Party room heart action is now a real clickable button in the room header beside the viewer count. It sends a room-scoped heart event and displays the shared real-time count. The old fixed top-right heart counter overlay was removed so it cannot sit over the Exit control.
2. Existing Party double-tap heart reaction behavior remains in place.
3. Local media capture now retries microphone-only capture when combined camera+microphone capture fails. This allows audio publishing to continue when camera capture is unavailable, subject to microphone permission and SFU/network availability.
4. Party and Solo Live user-facing connection messages were changed to Alpha Mate reconnecting / generic network wording instead of exposing provider/SFU names or raw backend errors in the visible UI.

IMPORTANT VALIDATION LIMITS:
- This environment uses Node 22.16.0 while this project and several installed dependencies require Node >=24.12.0.
- npm dependency installation did not complete within the available execution window, so TypeScript/Vite build was not run.
- No two-device Android test was possible here. Do not treat this ZIP as proof that end-to-end Party/Solo audio is fixed. Verify mic publish, remote subscription, playback/autoplay, role permissions, camera-off audio, and reconnect behavior on two physical devices with Node 24.12+ build environment.
- No signing keystore or signing credentials were modified or included.
