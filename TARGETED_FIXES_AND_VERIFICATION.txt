ALPHA MATE TARGETED FIXES - 14 NOV 2026

Scope: Preserve existing UI and working product flows. Targeted fixes only.

Changes in this source update:
- Solo Live heart action is now an interactive button placed beside viewer count in the top action row, separate from Exit. The existing shared Firestore heart counter and double-tap event path remain in place.
- Solo Live camera-off profile background now uses the existing HD image URL utility. Actual sharpness remains limited by the resolution of the uploaded source image.
- WebRTC media capture now has bounded camera/microphone acquisition timeouts and microphone-only fallback, so a stalled camera request cannot leave the live screen loading indefinitely.
- Solo Live and Party SFU setup now warms backend health and TURN credentials concurrently. Backend health checks and SFU API retries/timeouts were shortened to avoid excessive startup stalls; TURN remains optional with existing STUN fallback.
- SFU publishing prioritizes Opus voice and constrains video bitrate/frame rate to reserve bandwidth for audio on weak networks.
- Party remote audio playback no longer mutates receiver-owned MediaStreamTrack.enabled state.
- Chat user search now queries authenticated Firestore user profiles (usernameLower/displayNameLower/uniqueIdLower) instead of the local mock registeredUsers array. Profile sync writes normalized search fields. Search requires users to have a synced Firestore profile.
- Android CI uses Node 24.12.0 and refuses to produce release APK/AAB when signing secrets are missing. It verifies release APK with apksigner. Existing GitHub secrets are read through supported secret-name fallbacks.
